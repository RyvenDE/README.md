## Security & Research Principles

Security research requires more than discovering an exposed service.

My approach focuses on:

1. Identifying publicly observable infrastructure.
2. Collecting and correlating relevant technical information.
3. Assessing potential security implications.
4. Verifying findings only within authorized scopes.
5. Documenting reproducible evidence.
6. Reporting vulnerabilities responsibly.

I distinguish between publicly accessible information, potential vulnerabilities and confirmed security issues.

I do not consider unauthorized access, data extraction or disruption to be legitimate research methods.
